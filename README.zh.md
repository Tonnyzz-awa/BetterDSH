# BetterDSH
[English](README.md) | 中文

BetterDSH 是 [Deepseek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）的改进版，修复了多个 Bug，并新增了 HTML 和 Python 两种图形界面。BetterDSH 让 Deepseek Harness（DSH）更稳定、更易用——一个更适合日常使用的 Deepseek Harness（DSH）。

## 🚀 快速开始
### 环境要求
与 Deepseek Harness (DSH) 相同——[Node.js](https://nodejs.org) 22+ 和 [pnpm](https://pnpm.io)。
### 安装
```bash
git clone https://github.com/Tonnyzz-awa/BetterDSH.git
cd BetterDSH
pnpm install
pnpm run build
```
